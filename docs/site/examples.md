# Examples

Four example suites live under [`examples/`](https://github.com/nwilbert/pytest-given/tree/main/examples/), each with its JSON, Markdown, and HTML output committed. Each report below is the committed HTML, served from this site. The committed Markdown reports are on GitHub: [coffeeshop](https://github.com/nwilbert/pytest-given/blob/main/examples/coffeeshop/coffeeshop.md), [hotel-booking](https://github.com/nwilbert/pytest-given/blob/main/examples/hotel-booking/hotel-booking.md), [file-glossary-booking](https://github.com/nwilbert/pytest-given/blob/main/examples/file-glossary-booking/file-glossary-booking.md) and [self-report](https://github.com/nwilbert/pytest-given/blob/main/examples/self-report/self-report.md). The [Markdown report](markdown-report.md) page explains how to read them.

- [`coffeeshop/test_coffeeshop.py`](https://github.com/nwilbert/pytest-given/blob/main/examples/coffeeshop/test_coffeeshop.py) · [report](examples/coffeeshop.html){ target=_blank } — the core surface: nested step blocks, `@given` fixtures with teardown, text and JSON attachments, t-string interpolation, given annotations (`Annotated[..., given(...)]`), step-recording helpers, parametrize tables with custom case IDs, formatted step text, and failure, skip and expected-failure rendering.
- [`hotel-booking/test_hotel_booking.py`](https://github.com/nwilbert/pytest-given/blob/main/examples/hotel-booking/test_hotel_booking.py) · [report](examples/hotel-booking.html){ target=_blank } — Domain Storytelling over a code-defined `Glossary`: single- and multi-clause `sentence(...)` rows, scenarios bound to them with per-sentence coverage, and kindless + undefined terms awaiting classification.
- [`file-glossary-booking/test_file_glossary_booking.py`](https://github.com/nwilbert/pytest-given/blob/main/examples/file-glossary-booking/test_file_glossary_booking.py) · [report](examples/file-glossary-booking.html){ target=_blank } — the same over a Markdown `FileGlossary`: name-based term access, kinds inferred from clause slots, one deliberately kindless term.
- [`self-report/`](https://github.com/nwilbert/pytest-given/tree/main/examples/self-report/) · [report](examples/self-report.html){ target=_blank } — pytest-given applied to its own backend suite, narrated in the vocabulary of [`GLOSSARY.md`](https://github.com/nwilbert/pytest-given/blob/main/GLOSSARY.md) (loaded as a `FileGlossary`) and generated from the whole suite rather than a hand-written test file.

One more folder holds no report: [`pytest-bdd/`](https://github.com/nwilbert/pytest-given/tree/main/examples/pytest-bdd) writes the quick start's coffee scenario with [pytest-bdd](https://pytest-bdd.readthedocs.io/), a Gherkin feature file plus step definitions. The [BDD page](bdd.md) walks through it and compares the two approaches and their reports.
